# RRBS-Analysis-Pipeline
This repository contains a pipeline for analysing Reduced Representation Bisulfite Sequencing (RRBS) data. The workflow performs quality control, read trimming, alignment, methylation calling, and downstream analysis of DNA methylation data.  The pipeline is designed to be reproducible and adaptable to different RRBS datasets.
## Workflow
1. `01_methylseq.sh`
### Purpose
   - Runs the nf-core/methylseq pipeline.
### Inputs
   - FASTQ files listed in `samplesheet.csv`
### Output
   - Output: methylation calls and cytosine reports...
### Usage
```bash
Scripts/01_methylseq.sh
```

2. `02_differential_methylation.R`
### Purpose
Performs comprehensive differential DNA methylation analysis between experimental groups using the methylation coverage data generated by `01_methylseq.sh`, with the following parts.

### Part 1. Identification of Differentially Methylated CpGs
* Identify **differentially methylated CpG sites (DMPs)** between the defined experimental groups (BPF vs Control).
* Quantify differences in DNA methylation levels between groups.
* Apply appropriate statistical criteria to determine significant differentially methylated positions.

### Part 2. Genomic Annotation of DMPs
* Annotate identified DMPs to their corresponding **genes and genomic features**.
* Characterize the distribution of DMPs across **CpG island contexts**, including islands, shores, shelves, & Open sea
* Determine the genomic locations and gene associations of significant DMPs.

### Part 3. Functional Enrichment Analysis
* Map genes associated with significant DMPs to relevant biological functions.
* Perform **functional enrichment analyses** to identify overrepresented:
  - Gene Ontology (GO) terms
  - Biological pathways
  - Molecular functions
  - Cellular components
* Investigate the potential biological processes associated with differential DNA methylation.

### Part 4. Enrichment of DMPs Relative to RRBS-MsPL Targets
* Assess the overlap between identified DMPs and **RRBS-MsPL target regions** in the reference genome.
* Evaluate whether DMPs are significantly enriched within RRBS-MsPL target regions compared with the expected genomic background.
* Quantify the degree of overlap and assess its statistical significance.

## Overall Workflow
   **Experimental groups → Differential methylation analysis → DMP identification → Genomic annotation → 
   CpG island context  annotation → Gene mapping → Functional enrichment → RRBS-MsPL target overlap and enrichment 
   analysis**

### Inputs
- Working directory (`direc`)
  - Directory containing the methylation_coverage data (../bismark/methylation_calls/methylation_coverage).
- Sample annotation file (`target`)
  - Excel file containing sample metadata and group assignments with columns: litter, sample, Group, batch, & File_names
- Worksheet name (`target_sheet`)
  - Name of the worksheet corresponding to the comparison (e.g., `Female_BBzP`, `Male_BBzP`).
- RRBS-MsPL annotation file (`mspl_target_ref`) containing the chromosome and genomic coordinates of the MsPL target columns
  - Excel file containing sample metadata and group assignments.

### Usage
```bash
Rscript scripts/02_differential_methylation.R \
    results/annotation \
    metadata/sample_sheetFA1.xlsx \
    Female_BBzP \
    metadata/RRBS_MsPl_genome_CpG_Feature_annt_40_220.xlsx
```
### Output
The script generates:
- Differentially methylated CpGs, Summary tables of significant results, Statistics (e.g., p-values, adjusted p-values, methylation differences), Figures...
- DMP annotation tables, summaries, and figures for genes and CpG island contexts.
- Functional enrichment tables and figures for DMP-annotated genes.
- DMP enrichment summary statistics, tables, and figures relative to RRBS-MsPL targets.
